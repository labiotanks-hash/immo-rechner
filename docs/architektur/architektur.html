So ist der Immo-Rechner gebaut

Ankaufskalkulation und FixFlip Pro als eigene Web-App unter immo-rechner.a2o-architekten.de. Ein Server bei Hetzner mit vier Diensten; Anmeldung über Supabase wie bei BauDoc, Analyse über die Claude API, WhatsApp-Gruppe „Objekte Immo“ live, Sprachnachrichten lokal transkribiert.

Ablauf

Vom Exposé zur Ankaufskalkulation

  1. Anmelden: Link oder Code von Supabase; die App prüft das Token bei Supabase und die eigene Zugangsliste, dann gilt ein eigenes Cookie (30 Tage).
  2. Unterlagen: hochladen oder aus „Objekte Immo“ anhaken. Die Bridge hat Texte, Fotos, PDFs und Sprachnachrichten schon gespeichert, Whisper die Sprachnachrichten schon transkribiert.
  3. Aufbereiten: ZIPs entpacken, Chat lesen, PDFs und Fotos einmal zur Files API hochladen.
  4. Claude: recherchiert den Markt im Web und ruft die Werkzeuge der App: kalkulation_rechnen, fixflip_rechnen, dokumente_erstellen.
  5. Dokumente: Ankaufskalkulation gelb und ohne Markierung (HTML + PDF), FixFlipPro-Rechner je Exit, JSON-Grundlagen, Quellen-Übersicht.
  6. Rückfragen laufen im selben Verlauf weiter; „Objektordner als ZIP“ liefert alles in der Dropbox-Struktur.

Sicherheit

Was wo liegt

  • Objekte, WhatsApp-Nachrichten und Transkripte bleiben auf dem Server in Nürnberg.
  • An Anthropic geht nur, was für ein Objekt ausgewählt wird; beim Löschen werden die Dateien dort mitgelöscht.
  • API-Schlüssel nur auf dem Server (geheim.json, 0600), in der App eingetragen, nie wieder angezeigt.
  • Repo öffentlich, aber ohne Schlüssel und ohne Daten.
  • WhatsApp-Bridge ist inoffiziell (whatsmeow): Sperrrisiko klein, aber vorhanden.
